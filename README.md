# Ocean Living Creatures Quiz

## Project Overview
This project is part of the IBM SkillsBuild Front-End Web Development program. It is an interactive web platform designed to educate users about ocean living creatures through engaging content and a quiz section.

## My Role: Quiz Section Developer
I am responsible for developing the quiz section, which includes:
- Creating an interactive multiple-choice quiz using HTML, CSS, and JavaScript.
- Implementing real-time feedback and score tracking.
- Ensuring a responsive and user-friendly design.

## Technologies Used
- **HTML, CSS, JavaScript** – Core development.
